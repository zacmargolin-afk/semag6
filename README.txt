SEMAG6 — blank gaming portal

This version intentionally contains NO games or game embeds.
It includes the Semag6 branding, responsive layout, search field, category filters and an empty games area ready for your own content.

DEPLOY WITH GITHUB + CLOUDFLARE PAGES
1. Create a GitHub repository named semag6.
2. Upload index.html to the top level of the repository and commit to main.
3. In Cloudflare, open Workers & Pages > Create application > Pages > Connect to Git.
4. Select your semag6 repository and main branch.
5. Build command: exit 0
6. Build output directory: /
7. Deploy. If the project name is available, the site can use https://semag6.pages.dev.

To add games later, add your own game cards and embed code to index.html.
